# Conditional B-Spline LOF Model: Math and Learning

This document describes the current `BasisGaussianLOFModel` mathematics and online learning flow.

## 1) Data and observed target

At step `t -> t+1`, inputs are:

- previous order book: `OB_t`
- current order book: `OB_{t+1}`
- market flow volumes during interval: `(buy_vol_{t+1}, sell_vol_{t+1})`

The model first builds an observed **limit-order-flow (LOF) change** by:

1. Reducing `OB_t` by market-flow consumption (sells consume bids, buys consume asks).
2. Comparing reduced `OB_t` to `OB_{t+1}` at each absolute price.
3. Expressing this around previous mid in depth coordinates `d = 0..D`, where `D = spread_max`.

Per side we get:

- non-cumulative depth-diff: `y_{t+1}(d)` (change at depth level `d`)
- cumulative depth-diff: `q_{t+1}(d) = sum_{j=0}^d y_{t+1}(j)`

The model **learns on `y`** (non-cumulative), then integrates to produce cumulative outputs.

## 2) Basis representation

Let:

- `K` = number of basis functions (`n_basis`)
- `p` = spline degree (`spline_degree`)
- `B in R^{(D+1) x K}` = fixed non-uniform B-spline design matrix over depths `d=0..D`

Then for each side:

`y_{t+1} = B w_{t+1}`

where `w_{t+1} in R^K` are latent basis weights.

Observed weight target:

`w_obs = B^+ y_obs`

where `B^+` is Moore-Penrose pseudo-inverse.

## 3) Non-uniform knot construction

Internal knot count is dimension-matched:

`n_internal = K - p - 1`

Internal normalized knot locations are generated by:

`u_i = (i/(n_internal+1))^gamma`, `i=1..n_internal`, `gamma = depth_profile_power >= 1`

This creates:

- denser spacing near best price (`u` near 0),
- sparser spacing far from best.

Open knot vector:

- `p+1` repeated zeros,
- internal knots,
- `p+1` repeated ones.

Optional manual `knot_positions` can override profile and are resampled to required `n_internal`.

## 4) Conditional mean on full raw LOB (no feature extraction)

Define raw state vector from `OB_t`:

`x_t = [bid_qty(d=0..D), ask_qty(d=0..D)] in R^M`, with `M = 2(D+1)`.

This is non-cumulative per-level size around mid, directly used as input.

Per side, the conditional Gaussian weight model is:

`w_t | x_t ~ N(Beta x_t, diag(sigma_t^2))`

where:

- `Beta in R^{K x M}` is learnable,
- `sigma_t in R^K` is per-basis std (diagonal covariance).

## 5) Online learning updates

Let:

- forgetting factor `gamma = decay`
- EWMA step `alpha = 1 - decay`
- ridge regularization `lambda = ridge_lambda`

### 5.1 Sufficient statistics for ridge regression

For each side separately:

- `Sxx_t = gamma * Sxx_{t-1} + x_t x_t^T`
- `Sxy_t = gamma * Sxy_{t-1} + w_obs,t x_t^T`

Then:

`Beta_t = Sxy_t (Sxx_t + lambda I)^+`

This is a robust online ridge-normal-equation update with forgetting.

### 5.2 Sigma update (EWMA per basis)

Using pre-update conditional mean:

`mu_pred,t = Beta_{t-1} x_t`

Residual:

`r_t = w_obs,t - mu_pred,t`

Per basis `k`:

`sigma_{k,t}^2 = (1-alpha) sigma_{k,t-1}^2 + alpha * r_{k,t}^2`

Then clipped for numerical stability and floored by `sigma_min`.

### 5.3 Predictive NLL tracked

Before parameter update, model computes Gaussian NLL under current predictive mean/variance:

`NLL_k = 0.5 * (log(2pi) + 2log sigma_k + ((w_obs,k - mu_pred,k)/sigma_k)^2)`

and stores EWMA of mean NLL.

## 6) From non-cumulative prediction to cumulative LOF

Given sampled or mean weights:

1. Predict non-cumulative curve:
   `y = B w`
2. Integrate from mid outward:
   `q(d) = sum_{j=0}^d y(j)`  (implemented as `cumsum`)

So cumulative paths used downstream are generated by integration of modeled non-cumulative diffs.

## 7) Parameters currently learned/maintained

Per side (`bid`, `ask`):

- `Beta` (conditional linear map from raw LOB to basis weights)
- `sigma` (EWMA per-basis std)
- `mu` (legacy unconditional EWMA mean retained as fallback/diagnostic)

Shared/fixed:

- `B` (B-spline basis matrix)
- `B^+` (pseudo-inverse)
- profile controls: `n_basis`, `spline_degree`, `depth_profile_power`

## 8) Output semantics

- The model is trained on non-cumulative LOF diffs `y`.
- Public cumulative outputs/samples are `q = cumsum(y)`.
- This matches the goal: basis models local non-cumulative structure, cumulative is recovered by integration.
