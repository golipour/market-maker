# A First-Principles Mathematical Roadmap for Online Price Modeling
## Nobitex USDT_IRT · 30s Intervals · Empirical Evidence + Theory

---

## Preface: Why the Current Framing Is Wrong

The GUIDE frames the problem as "fit and compare models via walk-forward NLL." This is correct
operationally but misses a prior and more important question: *what kind of stochastic object
is this process, and what does the theory of such objects tell us about the limit of
achievable prediction?* Without answering that, any model search is a hyperparameter sweep
in disguise, bounded by whatever model class we happened to consider.

The approach here is different:
1. Formalize the problem in measure-theoretic terms so we know exactly what we're minimizing.
2. Diagnose the empirical process against the theories that apply to it.
3. Derive what a model *must* represent to be theoretically non-deficient.
4. Then — and only then — identify solution classes that satisfy those constraints.

The data (8,700 rows, ~4 days, 30s intervals) provides surprisingly strong guidance.

## Part I: The Mathematical Problem

### I.1 State Space and Filtration

Let (Ω, 𝓕, ℙ) be a probability space. The observable at each interval is a random vector:

```
X_t = (Δmid_t, buy_vol_t, sell_vol_t, spread_t, ...)  ∈ 𝒳 ⊆ ℝ^d
```

The natural filtration 𝓕_t = σ(X_0, X_1, ..., X_t) is the sigma-algebra generated by all
observations up to and including time t. A model at time t is a conditional distribution:

```
P_θ(X_{t+1} | 𝓕_t)
```

where θ is an element of some parameter space Θ that may itself evolve: θ_t ∈ Θ.

**Critical distinction**: mid is an I(1) process (ADF p=0.50, unit root confirmed) while Δmid
is I(0) (ADF p=0.000, KPSS p≥0.10). This is not just a modeling choice — it is a
mathematical requirement. Any model that assigns probabilities directly to mid_{t+1} without
integrating out the unit root is placing mass on the wrong σ-algebra. The process we are
predicting is Δmid, and the model state space must live in the stationary world.

### I.2 The Prequential (Sequential Prediction) Framework

The walk-forward NLL loss is not an arbitrary engineering choice. It corresponds to the
*prequential likelihood* introduced by Dawid (1984), the only proper metric for sequential
prediction. Define:

```
L_T(ℳ) = (1/T) Σ_{t=1}^{T}  -log P_{θ_{t-1}}(X_t | 𝓕_{t-1})
```

This is the mean per-step NLL under the model ℳ, where θ_{t-1} uses only data through t-1.

**Theorem (Shtarkov/Rissanen)**: L_T(ℳ) can be decomposed as:

```
L_T(ℳ) = H_T(X) + KL(ℙ_true || P_θ) + O(log T / T)
```

where H_T is the empirical (Shannon) entropy of the observed sequence. The first term is
irreducible — it is the entropy of the true process and cannot be compressed. The second term
is the divergence from the true conditional distribution, and it goes to zero if and only if
the model is asymptotically well-specified.

**Consequence**: the minimum achievable mean NLL is the conditional entropy H(X_t | 𝓕_{t-1}),
the entropy of the observation given the entire past. You cannot do better than this even with
perfect knowledge of the past, because the remainder is the genuine randomness of the process.
Any improvement in L_T over a baseline model must come from *capturing mutual information
between X_t and 𝓕_{t-1}* that the baseline does not.

### I.3 The Fundamental Decomposition

```
L_T(ℳ) = H(X_t | 𝓕_{t-1})  +  D_KL(ℙ_true || P_θ)
           ─────────────────────   ──────────────────────
           Irreducible entropy      Model error (reduce this)
```

The target is to reduce D_KL by building models that extract the maximum mutual information
I(X_t ; 𝓕_{t-1}) = H(X_t) - H(X_t | 𝓕_{t-1}) from the filtration.

**Empirical measurement**: the discretized Δmid has empirical entropy H ≈ 3.90 bits (81 tick
states). A model that assigns the *empirical marginal distribution* (ignoring all past
information) scores 3.90 bits per step. The question is: how many bits can we extract from
the past?

## Part II: What the Empirical Process Actually Is

These are not exploratory findings. They are diagnostic tests against specific theoretical
models of price dynamics. Each one implies or rules out entire model classes.

### II.1 Finding 1: The Dominant Structure Is the Roll Bid-Ask Bounce

**Observation**:
- ACF(Δmid)[lag=1] = **-0.238** (t = -22.87, R² = 0.057)
- Cov(Δmid_t, Δmid_{t-1}) = **-1029.4**
- Roll implied half-spread: c = √1029.4 = **32.1 IRT** (actual mean spread = 88.6 IRT)
- **Roll bounce explains 47.7% of Var(Δmid)**

**Theory (Roll, 1984)**: In the simplest microstructure model, trades arrive as a sequence of
buys (Q_t = +1) and sells (Q_t = -1) with i.i.d. probability p_buy = 0.5. Each trade moves
the transaction price by c (the half-spread) against the mid. The observed mid-price change
is:

```
Δmid_t = c·(Q_t - Q_{t-1}) + ε_t
```

where ε_t is an i.i.d. information innovation (the "efficient" component). This generates
*exactly* a negative lag-1 autocovariance:

```
Cov(Δmid_t, Δmid_{t-1}) = -2c² · p_buy(1-p_buy)
```

At 30s intervals, the observed covariance is the *integrated* version of this: many individual
trades aggregate within the interval, but the signature remains because the last trade in
interval t determines the short-term bias at the start of interval t+1.

**Implication for models**: Any model that treats Δmid_t as conditionally mean-zero given
𝓕_{t-1} is **structurally misspecified**. The conditional mean is nonzero:

```
E[Δmid_t | Δmid_{t-1}] ≈ -0.238 · Δmid_{t-1}
```

This is exploitable. The production `conditional_mechanical_mixture` model's linear regression
of observed mid-delta on mechanical mid-delta captures *some* of this, but not through the
roll channel directly — it conflates the bounce with the mechanical impact, which are
theoretically distinct phenomena.

**What must a model do here?** Represent the AR(1) component of Δmid (or its underlying
cause: net order-direction imbalance across the interval) explicitly.

### II.2 Finding 2: Variance Is Not Constant (ARCH Effects)

**Observations**:
- ACF(Δmid²)[lag=1] = **+0.180**, [lag=2] = **0.203**
- Spearman ρ(|Δmid_t|, |Δmid_{t+1}|) = **0.214** (decays to 0.069 at lag 20)
- After large moves (|Δmid| > 2σ): 69.3% reversal rate (pure microstructure noise amplified)

**Theory (Engle, 1982 — ARCH)**: A process exhibits ARCH if:

```
Δmid_t = μ_t + σ_t · z_t,   z_t ~ i.i.d. D(0,1)
σ²_t = ω + α₁ε²_{t-1} + β₁σ²_{t-1}          [GARCH(1,1)]
```

The ACF of squared residuals being significantly positive is the *definition* of ARCH. This
means the process has **conditional heteroscedasticity**: σ²_t is time-varying and predictable
from the past.

The production model uses EWMA variance: σ²_t ← γσ²_{t-1} + (1-γ)ε²_{t-1}. This is
equivalent to **IGARCH(1,1)** (integrated GARCH), which imposes the constraint α + β = 1 and
implies infinite persistence of variance shocks. IGARCH is a degenerate case that is only
appropriate when the process is near unit-root in variance. The empirical ACF(Δmid²) decays to
near zero by lag 20, suggesting finite but slow persistence — properly captured by a
GARCH(1,1) with α + β ≈ 0.85-0.95, not forced to 1.

**Implication**: The theoretically correct model of Δmid is not just AR(1) in the mean — it
also requires GARCH dynamics in the variance. A model that ignores this leaves extractable
mutual information I(Δmid_t² ; 𝓕_{t-1}) > 0 on the table.

### II.3 Finding 3: The Distribution Is Not Gaussian (Severely So)

**Observations**:
- Δmid: skew = -0.355, kurtosis = **7.185** (excess; normal = 0)
- Student-t MLE fit: **ν = 0.378** (!) — a distribution with no finite moments at all
- Log-likelihood gain: **+3,967 nats** over Gaussian for the same data

A df of 0.378 sounds alarming, but it reflects two overlapping phenomena:
1. A 40.4% point mass at Δmid = 0 (no price movement in the interval)
2. Pareto-like tails in the nonzero distribution (Hill α ≈ 3.0-3.4, implying finite variance
   but infinite skewness/kurtosis)

The appropriate interpretation is that the marginal distribution of Δmid is a **mixture**:

```
Δmid_t = 0 with probability p_0(𝓕_{t-1})
Δmid_t ~ F_nonzero(·; θ(𝓕_{t-1})) with probability 1 - p_0
```

where F_nonzero has heavy tails. Candidate families for F_nonzero:
- **Normal Inverse Gaussian (NIG)**: closed under convolution, finite moments of all orders,
  parameterizes skewness and kurtosis separately, has ML-tractable density. Theoretically
  motivated by Brownian motion subordinated to an inverse Gaussian time.
- **Variance-Gamma (VG)**: Brownian motion subordinated to a Gamma clock. Similar to NIG but
  with exponential tails, slightly lighter.
- **Student-t with censoring at 0**: pragmatic but loses physical motivation.

The 3,967 nat improvement over Gaussian is not hyperparameter tuning — it is fixing a
**distributional misspecification** that currently costs nearly 0.46 nats per step.

### II.4 Finding 4: Three Spread Regimes, Not Two

**Observations**:
- P(spread < 10) = 0.287, P(10-50) = 0.219, P(50-200) = 0.342, P(≥200) = 0.152
- Conditional variance by spread tercile: regime 0 (tight) = 4573, regime 1 (medium) = 3210,
  regime 2 (wide) = 5158
- ACF(spread)[lag=1] = 0.516 — spread is *highly persistent*

**Interpretation**: The spread distribution is multimodal with three distinct regimes:

```
Regime A (tight, spread < 10 IRT, ~28%):   Competition zone — market makers crowding inside
Regime B (medium, 10-200 IRT, ~56%):        Normal operation
Regime C (wide, > 200 IRT, ~15%):           Illiquidity / external shock / venue stress
```

The nonmonotonic variance structure (tight spread has *higher* variance than medium) implies
that regime A is associated with high-frequency repositioning and rapid price discovery, not
with tranquility. The production `conditional_mechanical_mixture` model has a 2-component
mixture (market-driven vs refresh) which cannot represent this 3-regime structure in the spread.

**Theoretical requirement**: the spread S_t should enter as a *conditioning variable* in the
price model, not just as a secondary output. Specifically, σ²_t = f(S_t, σ²_{t-1}, ε²_{t-1})
where f is allowed to be regime-dependent.

### II.5 Finding 5: Volume Is Non-IID with Long-Range Autocorrelation

**Observations**:
- ACF(buy_vol)[lags 1,2,5,10,20,30] = [0.272, 0.204, 0.138, 0.137, 0.113, 0.090]
- No lag up to 30 falls below the 95% threshold (0.021)
- The ACF decays *too slowly* for a short-memory (ARMA) process

**Interpretation**: Volume exhibits long-range dependence or at minimum regime-switching with
persistent regime occupancy. There are two non-exclusive explanations:

1. **Hawkes process (clustering)**: trade arrivals cluster in time — one trade provokes
   responses. The intensity of a Hawkes process with exponential kernel follows:

   ```
   λ_t = μ + Σ_{t_i < t}  α·exp(-β·(t-t_i))
   ```
   
   At 30s aggregation, the Hawkes clustering appears as positive ACF in volume.

2. **Regime switching**: volume behaves differently across low/high activity regimes, and
   regime transitions are slow (hence slow ACF decay).

The production `hurdle_lognormal` model assumes the conditional parameters (p_0, μ, σ) evolve
via EWMA, which is a scalar first-order exponential smoother. This is equivalent to modeling
volume as **i.i.d. conditional on slowly-varying parameters** — it does not model the serial
correlation in volume *within* any given parameter regime. ACF(buy_vol)[1] = 0.272 is far
above the significance threshold, so this is not a small omission.

**Also**: the log-normal distribution for nonzero volumes is rejected by normality tests on
log-volume (p ≈ 0.000, log-sell skew = -1.52, excess kurtosis = 4.13). A better family is the
**Generalized Pareto Distribution (GPD)** or a log-normal–Pareto splice for the tail.

## Part III: Theoretical Bounds on Prediction Quality

### III.1 What Is Predictable vs. Irreducible

The total variance of Δmid decomposes:

```
Var(Δmid_t) = Var(E[Δmid_t | 𝓕_{t-1}]) + E[Var(Δmid_t | 𝓕_{t-1})]
               ─────────────────────────────────    ─────────────────────────────────
                   Predictable mean component            Conditional variance (itself
                   (Roll bounce: ~0.57 × 4320 =          partially predictable via ARCH)
                    ~2046 from AR(1))
```

Approximating:
- **AR(1) component** (Roll): removes ~5.7% of variance from one-step prediction error
  (R²_AR1 = 0.0568). This is small in R² terms but translates to a meaningful NLL gain
  because even a small bias in the mean shifts probability mass.
- **ARCH component**: ACF(Δmid²)[1] = 0.18 implies approximately 18% of variance-of-variance
  is predictable one step ahead. Correctly modeling this allows the distribution to be wider
  when it should be wider and narrower when it should be narrower.
- **Distributional correction** (non-Gaussian): +3967 nats over 8699 steps = 0.456 nats/step.
  This is a **guaranteed improvement** from fixing the distributional family, independent of
  any temporal structure.

### III.2 The Weak-Form Efficiency Question

The Efficient Market Hypothesis at the 30s scale says E[Δmid_t | 𝓕_{t-1}] = 0. Our data
**rejects this** via the AR(1) test (t = -22.87). The price process is *not* weakly efficient
at 30s, precisely because the microstructure (the bid-ask bounce) creates predictable serial
correlation that has nothing to do with information.

However: the information innovation ε_t (the "efficient" component in Roll's decomposition)
is i.i.d. by construction. The Roll-corrected residuals

```
ε_t = Δmid_t - 0.238·Δmid_{t-1}
```

should be approximately i.i.d. (conditional on GARCH variance), and their direction should
be unpredictable. Testing this:

- Corr(net_flow[t], Δmid[t+1]) ≈ 0.012 — flow does not predict next-step price direction
- Corr(imbalance[t], Δmid[t+1]) ≈ 0.000 — imbalance is contemporaneously correlated
  (0.127) but not predictive
- Corr((microprice - mid)[t], Δmid[t+1]) ≈ -0.017 — microprice is a poor directional signal

This is consistent with Kyle-Glosten-Milgrom-type theory: *at aggregate intervals*, the
information in order flow is already reflected in the current spread and mid, leaving almost
no exploitable residual for *direction* prediction. The exploitable structure is in:
1. Mean: the AR(1)/bounce
2. Variance: the ARCH dynamics and spread-conditioning

### III.3 Information-Theoretic Bound (Constructive)

Using a Gaussian model as the baseline, the information gains from each structural fix are
approximately:

| Structure | Mechanism | Estimated Gain |
|-----------|-----------|---------------|
| AR(1) mean correction | Roll bounce | ~0.03-0.06 nats/step |
| GARCH variance | Variance predictability | ~0.05-0.15 nats/step |
| Distributional family | Gaussian → NIG/t-mixture | ~0.46 nats/step (measured) |
| Spread regime conditioning | Time-varying σ by regime | ~0.02-0.08 nats/step |
| Zero-inflation | Hurdle structure | ~0.10-0.20 nats/step (for Δmid) |

The distributional gain dominates — it is not about temporal structure, it is about using the
correct family. This is the *first* thing to fix before any dynamic model improvement.

## Part IV: The Correct Mathematical Representation

### IV.1 The Unified State-Space View

The correct generative model is a **partially observed dynamical system**:

```
Hidden state:    Z_t = (R_t, σ_t, V_t)
Observed:        X_t = (Δmid_t, vol_t, spread_t)

Regime:          R_t ∈ {A, B, C}  [tight / normal / wide]
Volatility:      σ²_t = ω_r + α_r·ε²_{t-1} + β_r·σ²_{t-1}   [regime-specific GARCH]
Volume state:    V_t follows a Hawkes-intensity or HMM switching model

Observation:
  Δmid_t | Z_t, 𝓕_{t-1}  ~ Hurdle(p_0(R_t)) × NIG(μ_roll(Δmid_{t-1}), σ_t; α, β)
  vol_t  | Z_t             ~ Hurdle(π_0(V_t)) × GPD(shape, scale(V_t))
  spread_t | R_t            ~ LogNormal(μ_R, σ_R)  [Markov emission from regime]
```

This is not a model proposal — it is the *minimum representation that is consistent with the
empirical evidence*. Any model that omits one of these components is *observably
misspecified* against the data we already have.

### IV.2 Decomposition of Δmid_t

The price change at interval t decomposes as:

```
Δmid_t  =  φ·Δmid_{t-1}          [Roll bounce: φ ≈ -0.238]
          + σ_t · z_t              [scaled NIG innovation, z_t ~ NIG(0,1;α,β)]
```

where:
- φ is the AR(1) coefficient (Roll component)
- σ_t follows a GARCH process (possibly regime-dependent)
- z_t has a heavy-tailed NIG or Student-t distribution with ν ≈ 3-4

The GARCH equation for σ_t:

```
σ²_t = ω + α·(Δmid_{t-1} - φ·Δmid_{t-2})²  +  β·σ²_{t-1}
```

with α + β ≈ 0.90 (estimated from ACF decay of squared residuals). This is a proper
AR(1)-GARCH(1,1) model, a standard class in econometrics but notably absent from the
production suite.

### IV.3 The Regime Process

Let R_t ∈ {A, B, C} be a latent regime with transition matrix P = [p_{ij}]. The spread
marginal distribution has three modes, and regime determines:
- The GARCH parameters (ω_r, α_r, β_r)
- The probability of zero price move p_0(r)
- The volume distribution parameters

The regime transition can be modeled as:
1. **HMM**: R_t | R_{t-1} ~ Multinomial(P[R_{t-1}, ·]) — fully latent, estimated via EM
2. **Threshold model (SETAR)**: R_t = f(spread_t, vol_t) — observed state, no latency needed
3. **Probit/logit soft assignment**: q_t(r) = softmax(βᵀ·[spread_t, vol_t, ...]) — soft regime
   probability, compatible with end-to-end gradient descent

Approach 2 is preferable for online learning because it avoids the filtering problem (you
observe spread_t directly, so there is no hidden state to infer).

### IV.4 The Volume Process

Volume arrivals at 30s are the aggregate of a point process operating at sub-second timescales.
The theoretically correct framework is a **compound Hawkes process**:

```
N(t):   trade count process with Hawkes intensity λ_t
S_k:    size of the k-th trade, S_k ~ Pareto(shape) or GPD

vol_t = Σ_{k: t_{k} ∈ (t-1, t]}  S_k
```

At 30s, we observe only the aggregate. The relevant implication is that ACF(vol_t) decays
as a power law if the Hawkes kernel is long-memory. However, the observed ACF(buy_vol) decays
approximately geometrically (ratio ≈ 0.75 between lags), suggesting short-memory Hawkes or
regime switching rather than true long-range dependence.

For online use, the practical representation is a **self-exciting count model** on the 30s
aggregates. A simple but theoretically grounded choice:

```
E[vol_t | 𝓕_{t-1}] = μ + κ·vol_{t-1}    [AR(1) in volume]
Var(vol_t | 𝓕_{t-1}) = γ·E[vol_t | ...]^2 [overdispersed]
```

with innovations from a Negative Binomial distribution (which naturally captures the
overdispersion and zero-inflation that characterizes count-like volume data).

## Part V: The Online Learning Constraint

### V.1 Why Static Models Fail

The model must be *online* because the process is non-stationary. Formally: the data-generating
process ℙ_t is time-varying, i.e., there exists no single fixed measure ℙ such that
X_t ~ ℙ for all t. Evidence:

- The spread distribution evolves (30min of tight spread vs 30min of wide spread)
- The GARCH volatility is a time-varying state variable by construction
- The roll coefficient φ may itself vary as market microstructure changes

The correct framework is **online (sequential) Bayesian inference**: maintain a posterior
P(θ_t | 𝓕_t) and update it as each observation arrives. For nonlinear/non-Gaussian models,
this posterior is intractable, requiring approximation.

### V.2 The Kalman Filter as the Optimal Linear Baseline

For linear-Gaussian systems, the Kalman filter achieves the theoretically optimal
(minimum-variance) online state estimate. The state-space formulation:

```
State equation:    θ_t = A·θ_{t-1} + w_t,   w_t ~ N(0, Q)
Observation eq.:   X_t = H·θ_t + v_t,         v_t ~ N(0, R)
```

The Kalman filter gives the exact posterior P(θ_t | 𝓕_t) = N(θ̂_t, Σ_t) with recursive update:

```
Predict:  θ̂_{t|t-1} = A·θ̂_{t-1}
          Σ_{t|t-1}  = A·Σ_{t-1}·Aᵀ + Q

Update:   K_t = Σ_{t|t-1}·Hᵀ·(H·Σ_{t|t-1}·Hᵀ + R)⁻¹    [Kalman gain]
          θ̂_t = θ̂_{t|t-1} + K_t·(X_t - H·θ̂_{t|t-1})
          Σ_t = (I - K_t·H)·Σ_{t|t-1}
```

The EWMA update used in the production models is a **scalar Kalman filter** with A=1 (random
walk state), H=1, and a fixed ratio Q/R = (1-γ)/γ. This is one-dimensional and cannot
represent the joint state (φ, σ, regime) needed for a properly specified model.

A vector Kalman filter with state θ_t = (φ_t, ω_t, log σ_t²) would give theoretically optimal
online estimation for the linear-Gaussian approximation to the ARMA-GARCH model.

**The EWMA's sin**: using a single decay parameter to simultaneously track the mean *and*
the variance forces these to have identical memory. Empirically, the conditional mean
(Roll coefficient) should be relatively stable, while the conditional variance (GARCH) changes
on faster timescales. A vector Kalman filter with different Q/R ratios for each state dimension
resolves this.

### V.3 Beyond Gaussian: Particle Filters

For the non-Gaussian, regime-switching model, the exact posterior is:

```
P(Z_t | 𝓕_t) = P(R_t, σ_t, ... | X_0, ..., X_t)
```

which is analytically intractable. The principal approximation schemes are:

1. **Rao-Blackwellized Particle Filter (RBPF)**: analytically marginalize the Gaussian
   components (σ_t given R_t) and use particles only for the discrete regime R_t. This is
   exact for the Gaussian parts and achieves much better variance-efficiency than pure
   particle filtering for this structure.

2. **Variational Bayes (VB) / assumed density filtering**: approximate P(Z_t | 𝓕_t) as a
   product of simpler distributions; update the variational parameters via gradient descent at
   each step. Compatible with neural network integration.

3. **Extended / Unscented Kalman Filter (EKF/UKF)**: for smooth nonlinear state equations,
   linearize around the current estimate. Practical and fast; loses accuracy for highly
   nonlinear dynamics.

For the GARCH component, there is a celebrated result (Nelson, 1992): the GARCH(1,1) model
has an exact state-space representation, and the optimal filter for σ²_t is known in closed
form given Gaussian innovations. This breaks down for NIG innovations, but the EKF
approximation is well-studied.

### V.4 Online SGD and Forgetting

An alternative online learning paradigm is to parameterize the model with a neural network
and update with gradient descent, using exponential forgetting to track non-stationarity:

```
θ_t = θ_{t-1} - η · ∇_θ L(X_t; θ_{t-1})  +  forgetting regularization
```

where L is the prequential NLL. The forgetting can be implemented as:
- **L2 shrinkage to prior**: add λ||θ - θ̄||² (proximal gradient / elastic weight consolidation)
- **Fisher-weighted forgetting** (online EWC): penalize changes in directions that matter most
  for past predictions, identified by the online Fisher information matrix
- **Learning rate decay / warm-restart cycles**: periodically restart with increased learning
  rate to respond to distribution shifts

**Critical constraint for neural approaches**: the model at step t must use *only* θ_{t-1}
(pre-update parameters) to score X_t. This is the prequential contract. Standard mini-batch
SGD violates this because it uses future observations in the batch. For a neural model to be
valid in this framework, it must either:
(a) Use a strictly causal architecture (the current parameters score before being updated), or
(b) Be evaluated on held-out future data after training on past data (which is just the
walk-forward split operationalized).

The distinction matters: a neural network updated on a rolling window of 1000 steps with
batch SGD is *not* the same as a prequential predictor updated one step at a time, and the
NLL they achieve is not directly comparable to a proper online model.

### V.5 Where Neural Networks and Transformers Are and Aren't Appropriate

A transformer operating on a context window of past observations can, in principle, learn
any Borel-measurable function of the filtration — it is a universal approximator in the
functional space. However, several structural arguments constrain where it can help:

**Where neural nets add value:**
- Learning the nonlinear function between spread/volume state and the GARCH variance σ_t
- Learning regime transitions f(spread_t, vol_t) → P(R_t) without assuming a parametric form
- Modeling the *joint* distribution of (Δmid, vol, spread) with copula-like flexibility
- Incorporating high-dimensional orderbook shape features that parametric models cannot handle

**Where they add less than expected:**
- The Roll bounce (AR(1)) and GARCH variance dynamics are nearly linear — a linear model
  achieves near-optimal performance. Nonlinearity helps at the tail and at regime transitions.
- Transformers are fundamentally batch models. Making them truly online requires continual
  learning with catastrophic forgetting prevention, which is an active and unsolved research area.
- The 30s process has at most ~10,000 steps per day. A transformer with reasonable context
  length (256 steps) has ~10^6 parameters. This is severely overparameterized for online
  calibration and will regularize poorly without strong architectural priors.
- The empirical data shows ~0% linear predictive power for direction beyond the AR(1)
  component. Nonlinear models may find spurious patterns in 8,700 points that don't generalize.

**The RL angle**: RL is not directly relevant here because we want to estimate
P(X_t | 𝓕_{t-1}), not optimize a cumulative reward. However, the GARCH model *does* have
a natural RL interpretation: the variance estimate σ_t is a latent state that evolves via a
controlled system, and minimizing prediction loss is equivalent to value estimation in a
certain Markov decision process. This connection does not change the optimal model, but it
opens the door to value-function approximation methods for the state-space model.

## Part VI: Theoretical Solution Hierarchy (Derived)

The following is not a list of things to try. It is a hierarchy of models, each adding one
theoretically motivated component to the prior, ordered by the specific mathematical deficiency
each fixes.

### Tier 0: The Honest Baselines

Before any modeling, two baselines establish the achievable range:

1. **Marginal baseline**: assign the empirical marginal distribution to every step (ignores all
   past). Mean NLL ≈ H_empirical ≈ 3.90 bits ≈ 2.70 nats.
2. **Gaussian EWMA (production `residual`)**: captures slow parameter drift but misspecifies
   the distribution family. This is the current production benchmark.

Any model that fails to beat the marginal baseline uses more complexity to achieve less.

### Tier 1: Fix the Distribution (Obligatory)

The 3,967 nat improvement from Gaussian → Student-t is *distributional*, not temporal. Before
any temporal modeling:

**Model P1**: Hurdle-NIG for Δmid
```
P(Δmid_t = 0 | p_0) = p_0                    [EWMA of zero-indicators]
P(Δmid_t ≠ 0 | μ, σ, α, β) ~ NIG(μ, σ, α, β)  [online ML for NIG params]
```

Online update: the NIG family has sufficient statistics (mean, variance, mean of 1/|X|) that
can be EWMA'd. The hurdle probability p_0 is a separate EWMA on zero-indicators.

This should beat the production model by ≈ 0.45 nats/step on price without any temporal
structure.

### Tier 2: Add the AR(1) Mean (Roll Bounce)

**Model P2**: AR(1)-Hurdle-NIG
```
Δmid_t | Δmid_{t-1} ~ Hurdle(p_0) × NIG(φ·Δmid_{t-1}, σ, α, β)
```

where φ is estimated online via RLS or Kalman with a slow random walk prior on φ. Online RLS:
```
φ̂_t = φ̂_{t-1} + K_t·(Δmid_t - φ̂_{t-1}·Δmid_{t-1})
```

This adds the AR(1) correction on top of the distributional fix.

### Tier 3: Add GARCH Variance Dynamics

**Model P3**: AR(1)-GARCH(1,1)-NIG
```
ε_t     = Δmid_t - φ̂_t·Δmid_{t-1}
σ²_t    = ω + α·ε²_{t-1} + β·σ²_{t-1}
Δmid_t  = φ·Δmid_{t-1} + σ_t·z_t,   z_t ~ NIG(0,1;α_s,β_s)
```

Online update: σ²_t is a recursive equation (one step). α, β can be estimated by maximizing
the accumulated log-likelihood using online L-BFGS or a rolling window gradient update.

This is the econometric state-of-the-art for financial returns and is **non-deficient** with
respect to all the empirical findings above.

### Tier 4: Add Regime Conditioning (Spread State)

**Model P4**: Regime-Switching AR(1)-GARCH-NIG

Partition the spread into three regimes using observed S_t (no latency):
```
R_t = soft-assign(S_t) ∈ Δ³    [probability vector over regimes]
```

Regime-specific GARCH:
```
σ²_t = Σ_r  R_t[r] · (ω_r + α_r·ε²_{t-1} + β_r·σ²_{t-1})
```

This is a **Mixture of GARCHes** (M-GARCH), conditioned on the observed spread. Online
estimation: treat the regime-specific (ω_r, α_r, β_r) as separate parameter sets, each
updated only when the soft-weight R_t[r] is large. A two-timescale update separates fast
GARCH tracking from slow regime-parameter learning.

### Tier 5: Joint Model (Volume + Price)

**Model P5**: Full State-Space with Volume Memory

Add the volume model:
```
E[vol_t | 𝓕_{t-1}] = μ_v + κ·vol_{t-1}       [AR(1)-mean for volume]
vol_t | E[vol_t]    ~ Negative-Binomial(r, p) or Hurdle-GPD
```

The negative binomial captures overdispersion (which is severe: mean ≈ 400 USDT, variance
is much larger due to heavy tails). The AR(1) captures the ACF[1]=0.27.

The joint model also captures the (weak) contemporaneous correlation between net flow and
Δmid, which linear models can represent exactly. For MPC rollout, this matters because
volume and price changes are *not* independent: generating a volume scenario without
conditioning on the price regime produces incorrect joint paths.

```
  - Gaussian: Shapiro-Wilk, Q-Q plot
  - Student-t: AIC vs Gaussian, likelihood ratio test
```

### VII.5 Hawkes Test for Volume
```
Fit a univariate Hawkes process to buy_vol and sell_vol time series.
Branch ratio ρ = α/β (Hawkes): measures self-excitation strength.

If ρ > 0.5: Hawkes structure is important and the AR(1) approximation underfits.
```

```
On the full history, track EWMA mean and variance of Δmid on 1h windows.
Plot the time-varying moments — are there structural breaks?
Apply CUSUM test on squared residuals for variance break detection.
This tells us how quickly the model needs to adapt (sets the effective α/β decay rates).
```

## Part VIII: Key Theoretical Questions to Resolve

1. **Is the Roll coefficient φ ≈ -0.238 stable?**
   If yes: it's a structural microstructure constant, model it as a fixed (or very slowly
   varying) parameter. If no: it depends on regime or time-of-day and needs regime conditioning.

2. **What is the effective horizon of GARCH variance persistence?**
   The ACF(Δmid²) decays to near-zero by lag 20 (10 minutes). This constrains α + β < 1 and
   sets the window of variance predictability. Models with α + β ≥ 0.99 (IGARCH) overfit
   historical shocks; models with α + β < 0.85 underfit persistence.

3. **Is the zero-inflation in Δmid related to the same state as zero-inflation in volume?**
   If both zeros come from the same low-activity regime R_t, a joint hurdle structure is
   correct. If they are independent (volume arrives but price doesn't move), separate hurdles
   are appropriate. Empirically: corr(1[Δmid=0], 1[vol=0]) should be measured.

4. **Can the spread process be modeled as Markov, and of what order?**
   The ACF(spread)[1] = 0.516 suggests an AR(1) or AR(2) model for log-spread might suffice.
   If it can be modeled accurately, spread can be *generated* in MPC rollouts rather than
   treated as exogenous — improving the quality of counterfactual simulation.

5. **Does the MPC rollout benefit from joint (vol, price) simulation?**
   The current architecture treats volume and price as independent model outputs fed into the
   MPC optimizer. If vol and Δmid are conditionally dependent (corr ≈ 0.17 contemporaneously),
   joint simulation produces more physically realistic paths than independent sampling.

## Summary: What the Mathematics Demands

The following is what a theoretically non-deficient online price model *must* represent,
derived from the empirical evidence and the relevant theory:

| Requirement | Evidence | Mathematical Component |
|-------------|----------|----------------------|
| I(1) → model Δmid, not mid | ADF on mid | Differencing / I(1) treatment |
| AR(1) mean in Δmid | ACF[1]=-0.238, t=-22.87 | Roll bounce: φ·Δmid_{t-1} |
| Conditional heteroscedasticity | ACF(Δmid²)>0, vol clustering | GARCH(1,1) variance equation |
| Heavy-tailed innovations | Kurtosis=7.2, t-fit df=0.38 | NIG / Student-t / VG innovations |
| Zero-inflation | 40.4% zero Δmid steps | Hurdle structure over continuous part |
| Spread-regime conditioning | 3-modal spread, spread predicts σ | Regime-specific GARCH |
| Volume serial correlation | ACF(vol) > threshold at lag 30 | AR(1) or Hawkes for volume intensity |
| Online/prequential update | Non-stationarity of parameters | Kalman / RBPF / online SGD |
| Distributional fix (obligatory) | +3967 nats vs Gaussian | NIG/t family, not Gaussian |

The production models satisfy the last column partially: they have hurdle structure (flow),
EWMA-based variance tracking, and an online update. They do not represent: the AR(1) mean
correction, GARCH versus IGARCH distinction, the correct heavy-tailed family, or the
three-regime spread structure.

The roadmap is therefore: fix the distribution first (Tier 1), add the AR(1) (Tier 2), add
GARCH (Tier 3), add regime conditioning (Tier 4). Each tier is theoretically motivated by a
specific empirical finding, and the NLL gain from each can be measured separately. This is
not a search — it is a structured decomposition of the information available in the filtration.
